# Cybersecurity

A hands-on cybersecurity learning portfolio covering fundamentals, authorized labs, practical security tools, and technical writing as I build internship-ready skills.

## Learning Highlights

- Linux fundamentals, permissions, shell commands, and Bandit practice
- Networking foundations: OSI model, IP/MAC addressing, ports, TCP/UDP, DNS, and HTTP
- Wireshark packet analysis: DNS, TCP handshakes, HTTP request/response, display filters, Follow TCP Stream, and Export Objects
- Nmap host discovery and basic port scanning in authorized lab environments
- Python utilities for file listing, file hashing, and TCP port scanning
- Bash scripts for system information, permission reporting, and directory backups
- Technical writing connecting Nmap scanning with Wireshark traffic analysis

> Notes describe exercises actually completed. Exact target details, screenshots, scan output, and comparison results are included only when recorded; results are never fabricated.
