# TryHackMe — Nmap: Live Host Discovery

**Status in learning log:** Reported completed on Day 16.

## Learning summary
- Understand the goal of discovering live hosts before deeper scanning.
- Learn that discovery probes can be affected by host firewalls and network configuration.
- Interpret results in context rather than treating lack of response as proof that a host is absent.

## Command pattern

    nmap -sn <authorized-lab-network>

Use only the network range assigned to your lab or one you have explicit permission to test.
