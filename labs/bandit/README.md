# OverTheWire Bandit — Learning Summary

The learning log records practice through Bandit levels 0–20 across Days 2, 3, 5, and 10. This page summarizes the skill areas studied without publishing level passwords or challenge-specific secret values.

## Skills practiced
- Connecting to a training host over SSH
- Reading challenge instructions and identifying relevant files
- Navigating directories and viewing text files
- Searching for files and text
- Working with file permissions and ownership
- Understanding pipes, redirection, and command composition
- Recognizing encoding/decoding and data-transfer tasks at a beginner level

## Commands worth understanding

    ssh
    ls
    cd
    cat
    file
    find
    grep
    strings
    sort
    uniq
    base64
    tr
    xxd

Use each command according to the specific challenge instructions and learn what its output means rather than memorizing a single solution.

## Documentation and safety
- Never commit passwords, tokens, or challenge credentials.
- Prefer explaining the command, why it worked, and the general lesson learned.
- This summary reflects progress reported during study; this audit did not independently verify every level on the platform.
