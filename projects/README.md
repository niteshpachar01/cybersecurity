# Projects

This directory is for larger cybersecurity projects that have a clear objective, reproducible setup, documented design, and testing evidence.

## Current status

No standalone project is being represented as complete here yet. Small learning utilities remain in [tools](../tools/README.md). When a project is ready, give it a dedicated folder with:

- Problem statement and scope
- Architecture or workflow diagram where useful
- Requirements and setup instructions
- Safe, reproducible usage steps
- Testing approach and actual results
- Screenshots with sensitive information removed
- Limitations and future improvements

Major projects may be moved to a dedicated repository when they are independently usable and documented well enough to stand alone.

Only test systems and devices you own or have explicit permission to assess. Never commit secrets, credentials, or private data.
